## How we decided what counts as right

An answer is **correct** only if it behaves correctly (answers, says it isn't covered, or restricts, as the reference requires), states every critical fact from the experts' reference answer with the right values, contains nothing on the must-not list, cites at least one of the expected sources, cites nothing the user can't see, and, where follow-up is required, produces a work order draft with the expected key fields. Paraphrase is fine; wrong numbers are not. Checks run over every rendered field (headline, blocks, conflicts, what-you-can-do, work order). Numbers and forbidden tokens are checked with regular expressions; facts that need understanding are decided by a single LLM judge run. **Partially correct** = right behaviour, no must-not hit, at least half of the critical facts. A judge item with no verdict fails.

**Permission leaks** counts three checks per question: (1) every cited source is visible to the user; (2) everything the model was given is visible: all sources, the chunks behind computed facts, and every document behind a conflict in the context; (3) a scan of the displayed answer and work order for distinctive values (numbers with units, test points, parameters) that occur only in documents the user can't see.

**Not checked:** that each citation semantically supports its sentence. The validator checks that values, units and identifiers appear in the cited source, not that they refer to the same component or condition.
